# Dash

Left Shift fires a named `dash`. Faster than walk on ground and in air. After the burst, horizontal speed coasts instead of hard-stopping.

## Driving (Linux, named actions)

- Confirm. `moveRight down` 0.12s: walk delta.
- From spawn, `dash press`: larger x delta than the walk beat. Screenshot `dash.png`.
- Jump, then `dash press` while still airborne. Screenshot `airdash.png`.
- After the burst, no keys: x still changes for a beat. Screenshot `coast.png`.
