# Wall on the course

Climb column at tx=8 (far side of the start pit). Walk off the start ledge to YOU FELL. Dash on the start ledge. Jump, grab the far face, climb, wall-jump toward the heart.

## Driving (Linux)

- Confirm. `dash press` from spawn: x moves off 3.40, still on the start ledge. `dash.png`.
- Walk off the start ledge (no jump): YOU FELL in the hole. `fell.png`.
- Jump the pit, hold `moveRight` on the far column: y drops at x 7.625. Two states. `climb.png`.
- Space while on that face: wall-jump toward EXIT, over the pit. `walljump.png`.
